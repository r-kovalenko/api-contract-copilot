# Security policy

Report a suspected vulnerability privately through [GitHub private vulnerability reporting](https://github.com/r-kovalenko/api-contract-copilot/security/advisories/new). Do not post exploit details, credentials, or private data in a public issue. Include affected revision, reproducible steps with synthetic data, and likely impact.

This learning project supports the latest `main` revision only; it is not approved for production data. There is no promised response-time SLA. Exposed credentials must be revoked/rotated immediately; removing a value from the latest commit does not remove it from history.

See [the OWASP control baseline](docs/security.md) and [credential handling](docs/secrets.md).
