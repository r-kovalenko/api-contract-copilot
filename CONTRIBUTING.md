# Contributing

Pick an issue from the shared API Contract Copilot Project. Work on a feature branch and open a pull request against `main`. Keep each change focused and add tests for observable behavior and failure cases. Link the issue in the pull request.

Run the checks documented in the README before pushing. CI uses synthetic data and requires no LLM credentials. Do not put tokens or private data in code, fixtures, logs, or issues. Live model evaluation will be a separate opt-in workflow.

Use squash merges. Required CI must pass before merging; one-person development does not require a second reviewer. API contract fixture changes should include an explanation of the intended compatibility change.

Public visibility does not grant an open-source license. A license has not yet been selected.
